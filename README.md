# Веб-портфолио

Откройте index.html для просмотра многостраничного сайта. Для отправки заказчику подойдут portfolio.pdf и portfolio.html. Автономный HTML содержит все кейсы и изображения. Интернет нужен при переходе на внешние сайты из кейсов.

Для публикации распакуйте архив в корень публичного репозитория GitHub. В Settings → Pages выберите Deploy from a branch, ветку main и папку /(root). Сохраните и откройте адрес, который появится в разделе Pages.
